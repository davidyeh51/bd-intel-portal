## 🌟 核心特色

1. **模組化知識庫與全站多維搜尋**：
   - 支援即時關鍵字模糊檢索（標題、標籤、客單價、專利字號、主管姓名）。
   - 具備分類篩選標籤（4.1.3.1 開發商、4.1.3.1 市場訊息、4.1.3.3 海外市場、顧問簡報專區）。

2. **首發深度研調：三星螺絲成型機有限公司（朝璟精機）**：
   - **實質客單價**：司法判決認證（臺灣高等法院臺南分院 114年度上字第149號）單台合約價 **415 萬元新台幣**（未稅）。
   - **商業模式全景圖**：解構簽約訂金（約 23%）、日本核心件進口＋台灣機座、自製專利模組與尾款驗收機制。
   - **主體釐清**：非台南上市公司三星科技（5007），實為雲林斗南近 30 年歷史之朝璟精機體系。
   - **前線業務作戰卡**：三大常見客戶異議（壓價、品牌混淆、交期催促）之破解邏輯與反擊金句，支援一鍵複製。

3. **無雜訊頂尖顧問簡報（Zero-Noise Consulting Deck）**：
   - 嚴格落實森秀明 8 種無雜訊版型（一對一、並列、結合、連鎖、麥肯錫、對立、比較、BCG 矩陣）。
   - 頂部 Action Title 結論置頂，三大管顧風格混搭（McKinsey Navy・BCG Forest Green・Accenture Purple）。
   - 網頁內建 16:9 全螢幕互動播放器，並提供本地 `.pptx` 實體檔案下載。

4. **可持續擴充架構**：
   - 採資料驅動（JSON Data-driven）架構，新完成之業務會議或調研報告只需 2 步即可加入全站檢索。
