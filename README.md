## 🌟 核心成果亮點

1. **實質商業模式與金流全景圖**：
   - 核心問題回答：避開歐日機（1,200 萬以上）與大陸廉價機（150 萬），以單台 **400～500 萬元** 價格帶，切入汽機車特殊長螺栓代工廠與外銷新興國（印度、土耳其、巴西）。
   - 金流進出結構：以少量高毛利整機組裝、客製翻轉夾具加價款與常態耗材為流入；日本軸承進口件與外包機加工為流出。

2. **司法判決真實客單價（公開覆核）**：
   - 臺灣高等法院臺南分院 114年度上字第149號民事判決載明：長衝程特殊零件成型機（PF86L/13B）單台合約價為 **新台幣 415 萬元（未稅）**。
   - 簽約預付訂金約 23.1%（96 萬元），到廠試車後收取尾款。

3. **企業主體釐清**：
   - 非台南上市公司「三星科技(5007.TW)」，無任何股權與從屬關係。
   - 實為雲林斗南近 30 年老牌機械廠「朝璟精機有限公司（統編：24408648）」廖氏家族（廖彥榮、廖冠傑）之雙軌營運品牌。

4. **前線業務 1 頁式作戰卡（Battle Card）**：
   - 內建一鍵複製功能，業務隨身攜帶「基本輪廓、415 萬底價、三大現場攻防話術（壓價破解、品牌澄清、驗收合約）」。

5. **無雜訊頂尖顧問簡報（Zero-Noise Consulting Deck・12 頁）**：
